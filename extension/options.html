X → Claude Code

Gönderiler bu Mac'teki yerel relay üzerinden Claude Code oturumlarına gider.

Proje klasöründe npm run extension:config çalıştırdıysan boş bırak; token eklentinin relay.json dosyasından okunur. Elle girmek istersen npm run token çıktısını yapıştır.
İstersen ~/.x-to-claude/config.json içindeki extensionId alanına yaz; relay yalnız bu eklentiden gelen istekleri kabul eder.
